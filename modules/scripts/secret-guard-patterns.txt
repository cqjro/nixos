# secret-guard patterns: tier|flags|modes|label|extended regex (grep -E)
#
#   tier   strong = high confidence, always blocks; weak = noisy, skipped when the
#          prompt contains the bypass token [allow-secret-pattern]
#   flags  i = case-insensitive, - = none

#          (path arguments only), pt = both; b (with t) = only when the tool is Bash
#   label  what the hook reports to the user (the matched text is never reported)
#

# anchored on a vendor prefix where one exists; that is what keeps this
# false-positive-free enough to leave on.
