# logged-out, public and a read-only GET. Every host a page redirects to must be covered

# domain its per-site CSS rule is keyed on (google.com, youtube.com, reddit.com,
# wikipedia.org, ...), or the shot shows nothing about that rule. Each page is a different
# page TYPE of its site, so the theme meets as many of its layouts as possible; up to about
# eight to ten per site (a run is ~40 s per page, see docs/agents/theme-shots.md).
